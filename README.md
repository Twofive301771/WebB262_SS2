# WebB262_SS2
SomaShare solution for WEB B 262 SS2

This GitHub repository consists of the digital solution to the SomaShare platform.

To make use of the SomaShare platform with minimal errors, all files are to be dowloaded and opened and ran using Visual Studio.

To create the SomaShare platform, Visual Studio and SQL were made to create the website and database structure respectively.
